== Debugging

Use Visual Studio Code to debug GDCubism:

. Add `debug_symbols=true optimize=none` to the SCons build command.
. Add the appropriate configuration below to `launch.json`.
. Open the `demo` project in Godot Engine and export it.
.. The repository includes a `demo.export` directory for this purpose.
. Start the debugger.


=== Windows

[source, json]
----
{
    "name": "Debug (Windows)",
    "type": "cppvsdbg",
    "request": "launch",
    "program": "${workspaceFolder}\\demo.export\\demo.exe",
    "externalConsole": true,
    "logging": {
        "moduleLoad": false,
        "trace": true
    },
    "cwd": "${workspaceFolder}\\demo.export",
}
----


=== macOS

[source, json]
----
{
    "name": "Debug (macOS)",
    "type":"cppdbg",
    "request": "launch",
    "program": "${workspaceRoot}/demo.export/demo.app/Contents/MacOS/demo",
    "stopAtEntry": false,
    "launchCompleteCommand": "exec-run",
    "osx": {
        "MIMode": "lldb"
    },
    "cwd": "${workspaceRoot}/demo.export",
}
----
